## 📌 О проекте

AutoSalon — современный многостраничный frontend-проект, созданный с акцентом на чистую структуру, адаптивность и удобство взаимодействия с пользователем.

Основная задача проекта — представить автомобили автосалона в удобном каталоге и предоставить пользователю быстрый путь от просмотра автомобиля до отправки заявки.

Проект разработан с использованием семантической HTML-разметки, БЭМ-методологии, модульного JavaScript и адаптивной вёрстки.
