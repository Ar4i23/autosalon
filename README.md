# КОБАЛЬТ — сайт автосалона

Тёмный премиальный сайт автосалона: каталог с фильтрами, трейд-ин, анимированная
статистика и форма заявки с валидацией в реальном времени.
Свёрстан по БЭМ, стили разбиты по блокам, JS построен на ES-модулях,
адаптив — от 320px до широких десктопов.

> **Демо:** `https://USERNAME.github.io/autosalon/` ← вставь свою ссылку после деплоя

## ✨ Возможности

- Тёмная тема по умолчанию + переключатель на светлую (сохраняется в `localStorage`)
- 🚗 Каталог автомобилей с живой фильтрацией по типу кузова
- ✅ Форма заявки с валидацией в реальном времени и автоформатом телефона
- 🔢 Анимированные счётчики, scramble-заголовок, бегущая строка, reveal-анимации
- 📱 Полная адаптивность: мобильные → планшеты → ноутбуки → десктопы
- ♿ Поддержка `prefers-reduced-motion`
- 🧩 Без библиотек и сборщиков — чистые HTML / CSS / JS

## 📁 Структура проекта

```
autosalon/
├── index.html              # разметка (БЭМ-блоки)
├── README.md
├── .gitignore
├── docs/                   # скриншоты для README и документации
│   ├── preview-dark.png
│   ├── preview-light.png
│   └── mobile.png
├── css/
│   ├── style.css           # точка сборки: только @import блоков
│   ├── media.css           # ВСЕ медиазапросы (mobile-first)
│   └── blocks/             # один файл = один БЭМ-блок
│       ├── vars.css        #   переменные и темы
│       ├── base.css        #   сброс, база, утилиты, кнопки
│       ├── header.css      #   шапка, лого, nav, тема, бургер
│       ├── hero.css        #   первый экран + характеристики
│       ├── marquee.css     #   бегущая строка
│       ├── catalog.css     #   фильтры + карточки авто
│       ├── about.css       #   преимущества + счётчики
│       ├── tradein.css     #   промо-блок трейд-ин
│       ├── order.css       #   форма заявки + экран успеха
│       ├── footer.css      #   подвал
│       └── fx.css          #   reveal, keyframes, reduced-motion
└── js/
    ├── main.js             # точка входа, инициализация модулей
    └── modules/
        ├── theme.js        #   переключение темы
        ├── menu.js         #   бургер + блокировка скролла без сдвига
        ├── scramble.js     #   «декодирование» заголовка
        ├── reveal.js       #   появление блоков при скролле
        ├── counter.js      #   анимированные счётчики
        ├── filter.js       #   фильтр каталога
        ├── preset.js       #   предзаполнение формы по кнопкам
        └── form.js         #   live-валидация формы
```

## ✅ Выполненные требования

| Требование                    | Реализация                                                   |
| ----------------------------- | ------------------------------------------------------------ |
| БЭМ                           | `блок__элемент--модификатор`, строгая иерархия               |
| Стили по блокам в одном файле | `css/blocks/*` собраны в `style.css` через `@import`         |
| Медиазапросы отдельно         | `css/media.css`, mobile-first                                |
| JS-модули                     | `js/modules/*`, вход через `<script type="module">`          |
| Адаптивность                  | брейкпоинты 380 / 480 / 768 / 1024 / 1280 + ландшафт и тач   |
| Тёмная тема + кнопка          | `data-theme` на `<html>`, токен-переменные, `localStorage`   |
| Live-валидация формы          | события `input`/`change`, маска телефона, блокировка сабмита |

## 🚀 Запуск локально

ES-модули не работают с `file://` — нужен локальный сервер:

```bash
# любой из вариантов
python -m http.server 8000
npx serve .
# или расширение Live Server в VS Code
```

Открыть: `http://localhost:8000`

## 🌐 Деплой на GitHub Pages

1. Залить репозиторий (см. ниже).
2. В репозитории: **Settings → Pages → Source: Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)` → **Save**.
4. Через 1–2 минуты сайт доступен на
   `https://USERNAME.github.io/autosalon/`.

Все пути в проекте относительные, поэтому Pages работает без настройки базового пути.
